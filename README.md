# ألعاب الأصدقاء

موقع ألعاب أونلاين بالعربي: لاعب ينشئ غرفة ويرسل الرابط، والباقون يدخلون من الجوال أو الحاسوب. **وحدك؟** كل الألعاب تُلعب ضد الكمبيوتر.

## موجود في كل الألعاب

- **لاعبو الكمبيوتر:** يضيفهم المضيف من غرفة الانتظار بزر "أضف لاعب كمبيوتر" ويحذفهم بـ ✕. يلعبون بإنصاف: لا يعرفون إلا ما يراه إنسان في مقعدهم.
- **التفاعلات:** زر الوجه يرسل إيموجي يطير فوق اسم المرسل عند الجميع.
- **إنهاء الغرفة:** زر "إنهاء الغرفة" للمضيف في غرفة الانتظار وفي القائمة أثناء اللعب وفي شاشة النهاية: بعد التأكيد يرجع الجميع للصفحة الرئيسية ويتوقف الكود. والباقون عندهم "الخروج من الغرفة": في الانتظار يُحذف مقعدهم فوراً، وأثناء اللعب يبقى مقعدهم ويلعب الخادم عنهم.
- **الانقطاع:** من ينقطع يرجع لمقعده نفسه تلقائياً. إذا جاء دوره وهو منقطع يلعب الخادم عنه بعد ثوانٍ قليلة، وإذا لم يبقَ أي إنسان متصل تتوقف المؤقتات حتى يرجع أحد.
- **الصفحة الرئيسية (`/`):** بطاقة لكل لعبة، وفلاتر (الكل، ورق، لوح ونرد، ذكاء وسرعة) يُحفظ آخر اختيار منها، وقائمة بكل الغرف المحفوظة للرجوع إليها.
- **تطبيق على الجوال:** الموقع يُثبَّت كتطبيق بأيقونته ويفتح بشاشة كاملة: زر "ثبّت التطبيق" في الصفحة الرئيسية (أندرويد والحاسوب)، وعلى آيفون من زر المشاركة ← "إضافة إلى الشاشة الرئيسية". بلا إنترنت تظهر صفحة "ماكو إنترنت" بدل خطأ المتصفح.

### ملفات التطبيق

- `public/manifest.json`: الاسم والألوان والأيقونات واختصارات الألعاب.
- `public/sw.js` (عامل الخدمة): **لا يخزّن الألعاب**؛ الصفحات تُجلب من الشبكة دائماً، فيصل أي تحديث فوراً ولا يلعب أحد بنسخة قديمة لا تطابق الخادم. لا يُخزَّن إلا `offline.html` وما تحتاجه. إذا غيّرت ملفات صفحة عدم الاتصال غيّر اسم `CACHE` في الملف.
- `public/pwa.js`: يسجّل عامل الخدمة في كل الصفحات، ويعرض صندوق التثبيت في الصفحة الرئيسية (ويخفيه بعد "لاحقاً").
- `public/icons/`: `icon.svg` هو الأصل، ومنه `icon-192.png` و`icon-512.png` و`maskable-512.png` (بهامش آمن لأندرويد) و`apple-touch-icon.png`.

## النشر على الإنترنت (Render، مجاناً)

> العلامة **(أنت)** تعني خطوة فيها حساب أو تسجيل دخول أو كلمة سر: نفّذها بنفسك.

### قبل أن تبدأ: ماذا تتوقع من الخطة المجانية

- **الخادم ينام** بعد 15 دقيقة بلا أي لعب، ويصحو تلقائياً عند أول زيارة. **الصحو يأخذ حوالي دقيقة**: افتح الرابط قبل اللعب بدقيقة.
- أثناء اللعب لا ينام (رسائل اللعب تُبقيه صاحياً).
- **الغرف في الذاكرة فقط**: إذا نام الخادم أو أُعيد تشغيله (أو نشرت تحديثاً) تضيع الغرف المفتوحة. اللعبة تعرض للاعبين رسالة "انتهت الغرفة" وزراً لإنشاء غرفة جديدة.
- 750 ساعة تشغيل مجانية في الشهر، تكفي لأن الخادم ينام معظم الوقت.

### الخطوة 1: ارفع المشروع على GitHub

1. **(أنت)** ادخل إلى <https://github.com> وسجّل دخولك (أو أنشئ حساباً).
2. **(أنت)** اضغط **New repository**، اكتب الاسم `screw-game`، اختر **Private** أو **Public**، ولا تضف README أو .gitignore (موجودان عندنا). اضغط **Create repository**.
3. افتح Git Bash داخل مجلد المشروع، ونفّذ هذه الأوامر (استبدل `USERNAME` باسم حسابك في GitHub):

   ```
   git init -b main
   git add .
   git commit -m "Screw game"
   git remote add origin https://github.com/USERNAME/screw-game.git
   git push -u origin main
   ```

4. **(أنت)** عند `git push` قد تفتح نافذة تسجيل دخول GitHub: سجّل دخولك ووافق.

> ملف `.gitignore` يمنع رفع مجلد `node_modules`، وهذا مقصود: Render يثبّت المكتبات بنفسه.

### الخطوة 2: أنشئ الخدمة على Render

1. **(أنت)** ادخل إلى <https://dashboard.render.com> وسجّل دخولك.
2. افتح المشروع (مثلاً **My project**) واضغط **Create new service** ← **Web Service**.
3. **(أنت)** في **Source Code** اختر **GitHub** واربط حسابك إن طُلب منك، وامنح Render صلاحية الوصول للمستودع `screw-game`، ثم اختره.
4. اكتب الإعدادات كما يلي:

   | الحقل | القيمة |
   |---|---|
   | Name | `screw-game` (يصير جزءاً من الرابط) |
   | Language | `Node` |
   | Branch | `main` |
   | Region | `Frankfurt (EU Central)` (الأقرب لنا) |
   | Root Directory | اتركه فارغاً |
   | Build Command | `npm ci` |
   | Start Command | `npm start` |
   | Instance Type | **Free** |

5. في **Environment Variables** أضف: `NODE_VERSION` = `22`.
6. افتح **Advanced** واكتب في **Health Check Path**: `/healthz`. اترك **Auto-Deploy** على **Yes**.
7. اضغط **Deploy Web Service** وانتظر حتى تظهر الكلمة **Live** (أول مرة تأخذ دقيقتين أو ثلاث).

> بديل أسرع: بدل الخطوات 2–6 يمكنك اختيار **New** ← **Blueprint** واختيار المستودع؛ Render يقرأ الإعدادات نفسها من ملف `render.yaml`.

### الخطوة 3: جرّب الرابط

1. في أعلى صفحة الخدمة يظهر رابط مثل `https://screw-game-xxxx.onrender.com`. افتحه.
2. اكتب اسمك واضغط **إنشاء غرفة**. إذا ظهرت غرفة الانتظار بالكود فالاتصال الآمن `wss://` يعمل (المتصفح يمنع الاتصال غير الآمن من صفحة https، فلو لم يكن آمناً لما فُتحت الغرفة).
3. اضغط **مشاركة الرابط** وأرسله لأصدقائك. يفتحونه من أي مكان، يكتبون أسماءهم، ويدخلون.

### تحديث اللعبة لاحقاً

أي تعديل ترفعه بـ `git add .` ثم `git commit -m "..."` ثم `git push` ينشره Render تلقائياً خلال دقائق. **تنبيه:** النشر يعيد تشغيل الخادم فتضيع الغرف المفتوحة، فلا تنشر أثناء لعب أصدقائك.

### إذا حدثت مشكلة

- **الصفحة تتأخر دقيقة ثم تفتح:** طبيعي، الخادم كان نائماً.
- **"انقطع الاتصال بالخادم":** اللعبة تحاول الاتصال تلقائياً. إذا عاد الخادم فارغاً تظهر "انتهت الغرفة" وزر لإنشاء غرفة جديدة.
- **فشل البناء في Render:** افتح **Logs** في صفحة الخدمة وأرسل لي آخر الأسطر.

## التشغيل على جهازك

يتطلب Node.js 18 أو أحدث.

```
npm install
npm start
```

يطبع الأمر عناوين مثل:

```
http://localhost:3000            ← من نفس الجهاز
http://192.168.x.x:3000          ← من الجوال (نفس الواي فاي)
```

- لاعب يضغط "إنشاء غرفة" ويرسل الرابط أو الكود (زر "مشاركة الرابط").
- الباقون يفتحون الرابط، يكتبون أسماءهم، ويدخلون. المضيف يضغط "ابدأ".
- إذا لم يفتح الجوال العنوان، تأكد أن الجهازين على نفس الشبكة وأن جدار الحماية في ويندوز يسمح لـ Node.js بالشبكات الخاصة.
- المنفذ الافتراضي 3000، ويمكن تغييره: `PORT=4000 npm start`.

## حدود الحماية (في `server/config.js`)

| الإعداد | القيمة | المعنى |
|---|---|---|
| `NAME_MAX_LENGTH` | 16 | أقصى طول لاسم اللاعب |
| `MAX_MESSAGE_BYTES` | 8192 | رسالة أكبر من هذا تقطع الاتصال |
| `MAX_ROOMS` | 200 | أقصى عدد غرف في نفس الوقت |
| `RATE_LIMIT_MESSAGES` / `RATE_LIMIT_WINDOW_SECONDS` | 40 / 10 | أكثر من 40 رسالة في 10 ثوانٍ تُرفض، وضعف ذلك يقطع الاتصال |
